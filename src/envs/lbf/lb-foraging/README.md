# Level-Based Foraging dependency

This directory contains a Python Level-Based Foraging environment based on
[semitable/lb-foraging](https://github.com/semitable/lb-foraging), used by PADiff
for training and evaluation. Its MIT license is in [LICENSE](LICENSE).

`PADiff/envs/lbf/lb-foraging` links to this directory so both training stages
use one copy.
